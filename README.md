# Nexonauts

An umbrella for developer tools that do their work on your machine, plus the writing that came out of building them.

| Product | What it is | Where |
| --- | --- | --- |
| Orbit | PDF toolkit that runs entirely in the browser | [orbit.nexonauts.com](https://orbit.nexonauts.com) |
| Recast | Screen recorder that edits the demo while you capture it | [recast.li](https://recast.li) |
| Glyphtex | LaTeX engine compiled to WebAssembly | [glyphtex.nexonauts.com](https://glyphtex.nexonauts.com) |
| Docvia | Framework agnostic documentation compiler | [docvia.dev](https://docvia.dev) |

The `nexo-*` packages and the architectural notes live at [docs.nexonauts.com](https://docs.nexonauts.com).

Live at **[nexonauts.com](https://nexonauts.com)**.
